## Conclusion mesurée
La production exécute le document par défaut de application.yml (profil DEV au sens d'ApplicationProfile), pas le profil 'prod'.
Conséquences : TntProdSecretsGuard inactif ; prometheus public ; le bloc 'springdoc ... enabled: true' du profil prod n'est PAS
ce qui ouvre Swagger en prod — c'est le défaut du document principal ; le bloc management.endpoint.health.status (C-20.2),
qui est dans le document principal, s'applique bien en prod.
